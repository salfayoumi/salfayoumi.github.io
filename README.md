# Salsabeel Alfayoumi — Portfolio

Personal portfolio for Salsabeel Alfayoumi, featuring work across Python, applied AI, data analysis, signal processing, and intelligent systems.

## Site

The portfolio is designed as a lightweight static site for GitHub Pages. It uses semantic HTML, responsive CSS, and a small amount of JavaScript for color-theme preferences and scroll reveals.

## Local preview

Run any static file server from the repository root, for example:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
