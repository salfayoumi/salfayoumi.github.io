Turkey Fuel Prices API

A packaged FastAPI MVP that turns official EPDK provincial fuel-price reports into structured JSON. Supports current observations, historical queries, distributor comparisons and dated price changes.

What the implementation does

  • Retrieves official HTML/XLS reports, normalizes provincial distributor observations, and exposes typed JSON through Pydantic response models.
  • Accepts province codes and Turkish or unaccented names, plus English/Turkish fuel aliases.
  • Validates dates and request ranges. Historical queries span up to 366 days by default and split upstream requests into periods of at most 93 days.
  • Uses in-memory caching with a 5-minute TTL for current queries and a 30-minute TTL for history.
  • Returns explicit validation, missing-data and upstream-unavailable errors. Includes source metadata and null values when exact comparison dates have no observation.

Run locally

Download and extract the source package, then run these commands from its root directory:

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8080

Open http://localhost:8080/docs to inspect the routes. The package includes a Dockerfile, deployment notes and an OpenAPI specification.

Project scope

This is a packaged MVP, available here as source. Prices come from dated official reports and reflect upstream publication and availability. The implementation uses in-memory caching; a persistent database and scheduled collection are outside the current package.
